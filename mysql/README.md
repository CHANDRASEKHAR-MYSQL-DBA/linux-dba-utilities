# MySQL Administration Scripts

This directory contains shell scripts for MySQL and MariaDB administration.

## Scripts

- mysql_status.sh
- backup.sh
- restore.sh
- replication_status.sh
- slow_query.sh
- user_audit.sh
process_monitor.sh

Monitors MariaDB processes and connections.

Checks:
- MariaDB service status
- Active connections
- Sleeping connections
- Maximum connection usage
- Long running queries
- Top running sessions
- Connection health status
