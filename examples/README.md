# Examples

This directory contains sample execution outputs generated while testing the Linux and MariaDB DBA utilities in the Rocky Linux lab environment.

## Example Categories

The examples demonstrate:

- Linux system health monitoring
- CPU usage monitoring
- Memory usage monitoring
- Disk usage monitoring
- MariaDB server status
- Database size reporting
- Replication status
- Slow query reporting
- User auditing
- MariaDB process and connection monitoring
- DBA health checks
- MariaDB backup
- Backup verification
- Backup rotation
- Restore validation
- Cron-based automation

## Purpose

These files provide visible evidence of script execution and make it easier to understand the expected report format without running the utilities first.

Generated runtime logs and production backup files are intentionally kept outside the repository.

## Testing Environment

```text
Operating System : Rocky Linux 9.8
Database         : MariaDB 10.11.8
Shell            : Bash
Virtualization   : Oracle VirtualBox
Architecture     : x86_64
```
