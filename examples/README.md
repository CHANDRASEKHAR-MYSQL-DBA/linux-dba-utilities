# Examples

This directory contains sample execution outputs generated while testing the Linux and MariaDB DBA utilities.

The examples demonstrate:

- Linux system health monitoring
- CPU usage monitoring
- Memory usage monitoring
- Disk usage monitoring
- MariaDB server status
- Database size reporting
- Replication status
- Slow query reporting
- User auditing
- MariaDB backup
- Backup verification
- Backup rotation
- Restore validation
- Cron-based automation
