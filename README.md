# Linux DBA Utilities

A collection of production-ready Linux shell scripts developed for MySQL and MariaDB database administration.

## Features

- Linux Server Health Monitoring
- MySQL/MariaDB Administration
- Backup Automation
- Restore Validation
- Replication Monitoring
- Disk Usage Monitoring
- Memory Monitoring
- CPU Monitoring
- Log Cleanup
- Cron Job Automation
- Database Health Checks

## Technologies

- Linux (RHEL/CentOS/Ubuntu)
- Bash Shell
- MySQL
- MariaDB
- Cron
- Systemctl
- mysqldump
- MariaBackup
